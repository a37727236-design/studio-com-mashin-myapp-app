1) Create a new GitHub repository and upload ALL files, keeping the folders (including the hidden .github folder).
2) Open the Actions tab > Build APK > Run workflow (it also runs on every push).
3) When the run is green, open it > Artifacts > app-debug-apk, download, unzip.
4) Install app-debug.apk on your Android phone (allow installing from unknown sources).

Note: this is a debug-signed APK, fine for testing and sharing. For stores you need a release key.
